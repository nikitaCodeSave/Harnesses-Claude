# Kit v2 переписан под большие проекты: один скилл и три шаблона

## Контекст

Оператор поставил задачу: harness под большие многосоставные проекты, с лёгким
стартом и для новых, и для текущих проектов, — и разрешил переписать кит целиком
или удалить его. Кит v1 (скилл с четырьмя режимами, ~3 000 строк справочников,
свод правил, копируемый в `.claude/docs/` каждого проекта с механикой
`shipped-by`) расходился с замерами #144–148. Удалять не стали: без кита
замеренный поток живёт только в лабе и в каждый проект переносится руками.

## Что сделано

Кит переписан в промежуточном клоне (`/tmp/kit-stage`, ветка `v2`, два коммита
поверх `f07fbd9`): один `SKILL.md` (три пути по состоянию репо — новый,
существующий без harness'а, существующий harness; раскладка для многосоставных
репо; Pocock по триггеру; permissions; верификация) и три шаблона — корневой
`CLAUDE.md` с блоками *How we work* и *Project knowledge*, `CLAUDE.md`
компонента, `settings.json`. Плагин переименован в `harness`: текущий Claude Code
резервирует имена на `claude-`, и `claude plugin validate` отклонял кит ещё до
переписывания. `native-capabilities.md` и `harness-evolution.md` переехали в
лабу (`.claude/docs/`), ссылки в 14 файлах лабы перенаправлены; роль кита в
`CLAUDE.md` и `README.md` лабы переписана — знание и замеры здесь, кит
устанавливает измеренный минимум.

## Проверка

- Механика кита переписана; каждая проверка поймала подложенный дефект.
- Поведение: три headless-прогона на Opus — A (новый большой проект), B
  (существующий монорепо, новая фикстура с запретом только в README, решениями с
  причинами, общим контрактом и вложенным `AGENTS.md`), C (harness с подсаженными
  дефектами). Первые прогоны вскрыли дыры обвязки теста (скилл требует разрешения
  `Skill`, запись `.claude/settings.json` — подтверждения, pipefail в проверке) —
  исправлены. Попутный контроль без скилла показал то, от чего кит защищает:
  карты модулей, выдуманная раскладка, `docs/architecture.md`.
- Независимое ревью свежим контекстом на опровержение: 15 находок, 14 приняты,
  одна опровергнута тестом (deny `Skill(mattpocock-skills:tdd)` ловит и голое
  имя). Главные: `AGENTS.md` Claude Code читает, пока нет `CLAUDE.md`, — корневой
  `CLAUDE.md` выключает вложенные (теперь мост на каждый); сессия, запущенная
  внутри пакета, не грузит корневые настройки; сторонние маркетплейсы не
  обновляются сами; часть замеров в §7 была сформулирована сильнее данных.
  Справочник `native-capabilities.md` лабы был устаревшим в части `AGENTS.md` —
  исправлен.
- Итог после правок: механика PASS, `plugin validate` PASS, сессии 16/16.

## Открыто

Слить ветку в кит, выпустить 2.0.0 (`release.sh`, тег, push) и поставить плагин
`harness` — за оператором: прямую запись в другой репозиторий и в `~/.claude`
классификатор auto-mode блокирует. Многосоставная раскладка не бенчмаркалась —
она следует правилам загрузки Claude Code и проверена только поведенческими
прогонами на фикстуре.
