# Глобальный слой пересобран абляцией с нуля

## Контекст

`~/.claude/` голый (#141). Оператор выбрал абляцию по методу Boris Cherny:
старт с почти ванили, каждый прежний компонент (кит, плагин `devlog`, скилл
`codex-mcp`) возвращается по одному — только когда его отсутствие реально
мешает. Кит и его репозиторий не тронуты.

## Изменения (вне репозитория, `~/.claude/`)

- `CLAUDE.md` (≈35 строк) — только невыводимое: язык чата, CLI-only подписка,
  где кит и лаба, спека как единица работы и как слой непрерывности (замещает
  несуществовавший «operator-global §6»), независимый проход свежим контекстом
  для класса silent-wrong. Поведенческих призывов нет — по Karpathy и по нашему
  архивному A/B они не работают.
- Три personal skill-**пробы** по мотивам `mattpocock/skills`, написаны своими
  словами, все `disable-model-invocation: true` (нулевая стоимость контекста до
  вызова): `/grill` — интервью раундами по дереву решений до спеки с исполняемым
  «Done when»; `/slice` — нарезка спеки на вертикальные срезы под один свежий
  контекст; `/retro` — нарушение → оракул раньше прозы, плюс поиск no-op строк.
- `settings.json` не менялся (приватность/прокси оператора).

Отступление: правило лабы велит создавать skills через плагин skill-creator;
его нет (плагины не установлены), поэтому SKILL.md написаны нативно.

## Проверка

Headless `claude --print` из `/tmp`: exit 0, отвечает по-русски со ссылкой на
операторский файл, видит `/grill` `/retro` `/slice` как user-only; предупреждений
о permission rules нет.

## Что стало неверным в живом слое лабы

Пока `devlog` не возвращён: «активен SessionStart-дайджест плагина devlog» и
`devlog-reindex` на PATH (`.claude/CLAUDE.md`, `principles.md`) — неверно,
reindex вызывается полным путём из репозитория кита. Путь канона
`~/.claude/skills/claude-code-harness/` (7 мест) — по-прежнему не существует.
Правка отложена до решения, что из компонентов возвращается.

## Поправка: глобальный CLAUDE.md удалён

Оператор отклонил файл. Построчный разбор: преамбула — заметка автору, не
модели; язык чата и конвенции репо — поведение по умолчанию; CLI-only — правило
лабы, ложное для любого проекта на Anthropic SDK; пути кита/лабы — знание одного
проекта, уже в `AGENTS.md`; спека — копия `workflow.md` кита (второй экземпляр
одного источника, конфликт с проектным CLAUDE.md после Bootstrap); проверка
свежим контекстом — уже в CLAUDE.md лабы. Системная ошибка: при выбранной
абляции написано 35 строк без единого наблюдённого сбоя. Глобальный слой пуст;
строка появляется в нём только через `/retro`, когда её отсутствие навредило в
проекте, где ей нет другого носителя.

## Критерий для проб

Проба становится кандидатом в кит только после применения на живом проекте с
наблюдаемым эффектом; не применялась за несколько недель — удаляется.
