# Вызов Codex в документации переведён на CLI

## Контекст

Инструкции лаборатории направляли Claude к сломанному MCP-подключению Codex.
Маршрут к внешнему ревьюеру должен совпадать с существующим user-scope скиллом,
а параметры вызова должны оставаться в одном месте.

## Изменения

В `.claude/CLAUDE.md` и `.claude/docs/multi-agent.md` §7.3 указан Codex CLI
через Bash и скилл `~/.claude/skills/codex-mcp/SKILL.md`. Имя `/codex-mcp`
сохранено; транспорт — `codex exec --json`, продолжение — `codex exec resume`
по точному ID. Для независимого ревью нужна новая сессия; для уточнения
найденного — продолжение выбранной. Удалены настройка `codex_peer` и MCP-параметры.
Сохранены триаж находок и требование read-only ревью.

## Проверка

`devlog-reindex` регенерирует производные индекс и дайджест без ошибок.
`git diff --check` чист; `claude plugin validate .` в репозитории кита прошёл;
permission health probe `claude --print "ok"` завершился с кодом 0 без
предупреждений о permission rules. Проверка двух изменённых документов
подтвердила маршрут к скиллу и отсутствие `codex_peer`/`mcp-server`
с положительным контролем на содержимом HEAD. Детектор версионного дрейфа
по-прежнему находит прежние совпадения; новые строки их не добавляют.
