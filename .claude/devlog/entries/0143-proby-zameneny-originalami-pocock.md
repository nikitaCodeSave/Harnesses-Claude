# Пробы заменены оригиналами Pocock

## Контекст

Самописные `/grill` `/slice` `/retro` из #142 пересказывали `mattpocock/skills`
со слов research-агента и расходились с его же механикой: у user-invoked
skill'а описание — строка для человека, а не список триггеров; `grilling`
задаёт весь frontier за раунд, а не 3–5 вопросов; дисциплина живёт в
model-invoked skill'е, а user-invoked — однострочная обёртка. Пересказ MIT-кода,
который поддерживает автор, — это форк, против которого стоит правило лабы.

## Изменения (вне репозитория)

- Клон `~/.local/share/mattpocock-skills` (v1.3.1, коммит `4588b32`), обновление
  через `git pull`. Глобальный git переписывает https→ssh, а ssh до GitHub с
  машины не резолвится; в клоне локальное правило `insteadOf` на тот же
  https-URL (более длинный префикс выигрывает).
- В `~/.claude/skills/` симлинки: `grilling`, `writing-for-agents`
  (model-invoked — их описания в контексте каждый ход); `grill-me`, `retro`,
  `setup-matt-pocock-skills`, `to-spec`, `to-tickets` (user-only, нулевая
  стоимость контекста). Самописные удалены.
- Трекер — локальный: после `/setup-matt-pocock-skills` в проекте спека живёт в
  `.scratch/<feature>/spec.md`, тикеты — `.scratch/<feature>/issues/NN-*.md`.
  Это расходится с форматом спеки кита (`specs/<slug>.md`, исполняемый «Done
  when»): для новой сборки принят формат Pocock, кит не тронут.

Проверка: headless `claude --print` видит в контексте ровно два model-invoked
skill'а (`grilling`, `writing-for-agents`); user-only в контекст не попадают.

## Ресёрч: файлы инструкций

Каталог — `external-sources.md`, блок 5. Главное: эксперименты не находят
значимого влияния файла на success rate, но фиксируют +20–23% стоимости (ETH)
и доказанно нулевой эффект размера 25→500 строк на соблюдение инструкций.
Конкретные нестандартные инструкции исполняются. Исследований глобального
файла нет. У индустрии глобальный файл — личное и межпроектное (общение,
личные инструменты, git/внешние действия), личный файл Boris ~76 токенов.
