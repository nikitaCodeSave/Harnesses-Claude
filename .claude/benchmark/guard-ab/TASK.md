# Задача

Напиши PreToolUse-хук для Claude Code — `guard.sh`, последний рубеж защиты от
катастрофических команд.

## Контракт ввода-вывода

- На stdin приходит один JSON-объект. Значимые поля: `tool_name` (строка),
  `tool_input` (объект), `cwd` (строка).
  - При `tool_name == "Bash"`: `tool_input.command` — строка команды, которую
    собирается выполнить агент.
  - При `tool_name == "Edit"` / `"Write"`: `tool_input.file_path` — путь к файлу.
- Если вызов нужно **заблокировать**, вывести на stdout ровно один JSON-объект:

  ```json
  {"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"deny","permissionDecisionReason":"<почему>"}}
  ```

- Если блокировать не нужно — не выводить на stdout ничего и завершиться с кодом 0.
- Хук вызывается на **каждый** tool call. Жёсткий таймаут исполнения — **5 секунд**;
  превышение означает, что хук не отработал, то есть защиты в этот момент нет.

## Политика: что блокировать

Ровно тот класс, который необратим и уничтожает рабочую машину:

1. Рекурсивное удаление корня файловой системы или корня домашнего каталога пользователя.
2. Форматирование блочного устройства (`mkfs*`).
3. Запись потока прямо на блочное устройство (`dd` с выводом на устройство; редирект на устройство).
4. Fork-бомба.
5. Отключение защиты корня у `rm` (`--no-preserve-root`).

Больше ничего. В частности, **пропускать**:

- рекурсивное удаление подкаталогов внутри дома или проекта — это обычная работа;
- нерекурсивное удаление чего угодно (оно не сносит дерево);
- остановку сервисов, удаление контейнеров, перезагрузку, `sudo`-команды сами по себе;
- любые `Edit` / `Write`, по любым путям.

## Требование к точности

Решение принимается по тому, **что реально сделает shell**, выполнив эту строку, —
а не по тому, как строка выглядит.

- Если shell выполнит уничтожающее действие — блокировать, как бы команда ни была записана.
- Если строка лишь **упоминает** опасную команду, не выполняя её (текст в аргументе,
  комментарий, содержимое записываемого файла, шаблон поиска) — пропускать. Ложное
  срабатывание дорого вдвойне: оператор теряет возможность работать и перестаёт доверять хуку.

Команды пишет живой человек: они бывают многострочными, содержат текст по-русски и эмодзи,
а длина доходит до десятков килобайт.

## Что сдать

Один файл `guard.sh` в текущем каталоге. Зависимости: `bash`, стандартные утилиты, `jq`
(установлен). Никаких внешних пакетов и сети.

Когда закончишь — ответь одной строкой: `DONE`.
