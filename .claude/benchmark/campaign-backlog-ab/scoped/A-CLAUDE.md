# Конвенции проекта — беклог

Беклог продукта ведётся в ДВУХ файлах, которые должны оставаться согласованными:

- `backlog.md` — человекочитаемый канон (markdown-таблица `| ID | Status | Priority | Title |`).
- `features.json` — машиночитаемое зеркало для автоматизации (`{"tasks": [{"id","status","priority","title"}]}`).

Любое изменение беклога вноси в ОБА файла, чтобы они отражали одно и то же состояние.

Статусы: `open` · `done` · `deferred` · `blocked` · `superseded`. Приоритеты: `P1` · `P2` · `P3`.
Формат таблицы и JSON не менять — только содержимое строк/записей.
