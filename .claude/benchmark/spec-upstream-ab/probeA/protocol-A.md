# Задание

Ниже — стенограмма грилл-сессии. Синтезируй из неё спеку задачи.

Выведи **только документ**, в ответе, без записи файлов и без кода реализации.

Каркас документа (PRD-lite, 1 страница):

```
Проблема:       что болит и у кого
Пользователь:   кто, в каком сценарии
Success (done): 3-5 наблюдаемых критериев (= acceptance criteria)
Ограничения:    что связывает решение
NON-GOALS:      что осознанно НЕ делаем
Открытое:       отложенные решения
```

Acceptance criteria — наблюдаемое поведение через публичный интерфейс,
не «сделать хорошо».
