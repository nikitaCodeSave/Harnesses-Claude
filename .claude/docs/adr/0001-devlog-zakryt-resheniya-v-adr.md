# 1. Devlog закрыт: решения — в ADR, замеры — в RESULTS.md, история — в git

Дата: 2026-10-28 · Решение оператора · Источник замеров: `.claude/benchmark/pipeline-ab/RESULTS.md`

## Context

Лаба вела эпизодический журнал `.claude/devlog/` (149 записей) через плагин `devlog`: после каждого
значимого изменения — запись, регенерация индекса, SessionStart-дайджест. Замеры 2026-10-27…28
показали, что знание между сессиями переносят носители, которые проект держит и без журнала:
решения с причинами — ADR, состояние работы — открытая спека, что изменилось — коммит, измерения —
`RESULTS.md` стенда. В многосессионном стенде ранние решения пережили сессии без всякого журнала, а
у плагина `devlog`, вызываемого моделью автоматически, нашёлся побочный эффект: установленный на
уровне пользователя, он заводит журнал в проектах, которые его не ведут (broker-bot: запись от
2026-07-23 вне git), включая те, где непрерывность устроена иначе (риск отмечен аудитом DataLake
2026-10-28; там он ещё не срабатывал). Журнал дублировал
все четыре носителя сразу и требовал поддержки собственного инструмента.

## Decision

- Новых devlog-записей нет. `.claude/devlog/` — замороженный архив: записи не правятся и не
  дополняются; ссылки вида «devlog #NNN» остаются провенансом и ведут в него.
- Решение, которому должна следовать будущая работа, — ADR в `.claude/docs/adr/NNNN-<slug>.md`
  (context / decision / consequences) в той же сессии, где оно принято. Отменяется не правкой, а
  новым ADR со ссылкой на прежний.
- Замер — `RESULTS.md` своего стенда в `.claude/benchmark/`; внешний источник —
  `.claude/docs/external-sources.md`; что изменилось и почему — сообщение коммита.
- Плагин `devlog` снят с лабы и удалён из кита (kit 3.0.0).

## Consequences

- Проверка документации — детектор дрейфа и проверка permissions из `AGENTS.md`; валидатор индекса
  devlog больше не нужен.
- Вывод из сессии, который раньше уходил в раздел «Урок» записи, теперь либо меняет живой документ
  (`.claude/docs/*`), либо становится ADR — либо не записывается вовсе.
- SessionStart-дайджеста нет: новая сессия начинает с `CLAUDE.md`, открытой спеки и ADR.
