# 7. Строка статуса ADR действует и в лаборатории

Дата: 2026-10-29 · Решение оператора

## Context

[ADR 0006](0006-arkhitektura-artefaktov-proekta-i-ikh-zhiznennyy-tsikl.md) ввёл для проектов кита
строку статуса ADR, а вопрос, распространять ли её на лабораторию, оставил оператору. В
лаборатории действовало «принятое ADR не правится». Из-за этого ADR 0004 уже частично отменён
ADR 0005, но по самому 0004 этого не видно.

## Decision

- Каждое ADR лаборатории начинается со строки `Status:` — `accepted`, `deprecated` или
  `superseded by NNNN`. Если отменена только часть, это сказано в той же строке.
- Строка статуса — единственная допустимая правка принятого ADR; текст не меняется. Отмену решения
  по-прежнему делает новое ADR, и оно же меняет статус старого.

## Consequences

- `AGENTS.md`, правило docs-discipline 3 и `memory-layers.md` говорят то же самое.
- ADR 0004 и 0006 получают статус с частичной отменой; остальные — `accepted`.
