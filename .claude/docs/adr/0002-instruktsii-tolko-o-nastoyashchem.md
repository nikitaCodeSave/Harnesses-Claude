# 2. Инструкции описывают только настоящее; история — в записях

Дата: 2026-10-28 · Решение оператора

## Context

Инструкции кита и лабы — скилл, шаблоны, мануал, `CLAUDE.md`, `AGENTS.md`, rules, рабочие доки —
копили даты, номера версий Claude Code и моделей, ссылки на журнал и рассказы о том, как пришли к
правилу. Всё это устаревает, занимает контекст при каждой загрузке и мешает отличить действующее
правило от пройденного. Одна и та же история уже хранится в git, ADR, `RESULTS.md` стендов и
CHANGELOG.

## Decision

- **Инструкции** говорят, как есть и почему: правило и причина, с цифрой, если цифра несёт
  решение. Без дат, версий, ссылок на журнал и нарратива «было → стало». Удалённый компонент из
  инструкций исчезает, а не описывается как удалённый.
- **Записи** держат историю и провенанс и в контекст не грузятся: git и сообщения коммитов, ADR,
  `RESULTS.md` стендов, CHANGELOG кита, аудиты (`.claude/audits/<slug>/`: новый пишет свою папку,
  записанные не правятся), архивы (`.claude/devlog/`, `.claude/docs/archive/`). Версии Claude Code и моделей названы в одном файле —
  `.claude/docs/native-capabilities.md`, вместе с refresh-ledger. `external-sources.md` — каталог
  источников: даты в нём — метаданные цитирования.
- Инструкция ссылается на запись, а не пересказывает её.

## Consequences

- Оракулы: в ките — механическая проверка M7 (даты, версии, журнал и фразы-истории в скилле,
  шаблонах, мануале, README); в лабе — детектор дрейфа из `AGENTS.md` по инструкциям, без записей.
- `SKILL.md` кита не несёт обоснований с цифрами — они в README (*How we work — and why*), для
  людей; контекст скилла — только то, по чему он действует.
- Правило docs-discipline 3 переписано под это решение; прежнее исключение для «датированного
  провенанса в активном слое» снято.
