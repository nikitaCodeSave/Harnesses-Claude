# 4. Кит строится под большие и долгие проекты; цена сама по себе слой не снимает

Дата: 2026-10-29 · Решение оператора

## Context

Стенд `pipeline-ab` (плечи N/C) показал: шаблон кита с обычным запросом даёт полную приёмку 9/9 и
стоит в 1.7–2.4 раза дороже того же потока, заданного строкой оператора (плечо S, 8/9, сравнение
между сериями). Из чего складывается надбавка, не разложено; `RESULTS.md` называет кандидатом
плечо «шаблон без *Project knowledge*». Многосессионный стенд L1 мерил слой знаний как страховку:
на передовой модели спина без правил переносит решения сама (3/3), правила стоят +17%; на слабой
модели без них 8/19, с ними 18/19. Накопление за месяцы — десятки фич и решений, разрастание
`SPEC.md` — не моделировалось, а именно там структура ADR вероятнее окупается.

Оператор: повышение цены ради потенциального качества и универсальной архитектуры, рассчитанной
на большие проекты, приемлемо.

## Decision

- Кит рассчитан на большие и долгие проекты; маленький проект получает тот же шаблон.
- Цена записывается в каждом замере, но сама по себе не основание снимать слой. Слой снимается,
  когда замер там, где он должен окупаться — большой или долгий проект, — не показывает выигрыша по
  качеству, или когда он качество снижает.
- Плечо «шаблон без *Project knowledge*» ради разложения цены не прогоняется: его ответ решения не
  меняет.
- На измеренном масштабе слой знаний дублирует привычку передовой модели. Он остаётся как страховка
  для неизмеренного масштаба и для более слабых моделей — это решение оператора, не результат замера.

## Consequences

- Следующий приоритетный замер — накопление: много фич и решений на одном проекте, включая
  отменённые решения и разросшуюся спеку. Если там слой знаний выигрыша не даст, решение
  пересматривается новым ADR.
- Цифры цены остаются в таблице `workflow.md` как информация для выбора потока, не как критерий
  удаления.
- Принцип «минимум обвязки» действует как прежде для компонентов, кодирующих неумение модели;
  этот ADR — осознанное исключение для слоя знаний, с условием пересмотра выше.
