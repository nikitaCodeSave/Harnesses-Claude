# 5. Слой знаний проекта безусловен; следующая работа — жизненный цикл артефактов

Дата: 2026-10-29 · Решение оператора · Отменяет условие пересмотра из [ADR 0004](0004-kit-pod-bolshie-proekty-tsena-ne-kriteriy.md)

## Context

ADR 0004 оставил слой знаний (`GLOSSARY.md`, ADR) страховкой и привязал его пересмотр к стенду
накопления. Стенд L2 собран: фикстура, оракул и самопроверка — `benchmark/pipeline-ab`, коммит
`b592318`. Но на его масштабе — около 1100 строк кода, восемь фич, решения, явно помеченные «на
будущее», — ни один правдоподобный исход решение не меняет. Если оба плеча у потолка, это не довод
снимать страховку для больших проектов. Если выиграет шаблон кита, это подтвердит уже принятое.

Основание держать слой — несколько независимых источников, а не один замер:
- многосессионный стенд L1: на слабой модели без правил 8/19, с ними 18/19; поток без ADR
  потерял решение «на будущее»;
- практика Pocock: `domain-modeling` ведёт глоссарий и ADR;
- внешние источники каталога `external-sources.md`.

Оператор: в большом проекте главный риск не в отсутствии артефактов, а в их жизненном цикле.
Завершение, отмена и изменение задач оставляют слоп и архаизмы, которые потом грузятся в контекст
как действующие.

## Decision

- Слой знаний проекта входит в кит безусловно. Стенды на масштабе одного небольшого проекта его не
  пересматривают; пересмотр — только по данным большого или долгоживущего проекта.
- Стенд L2 не прогоняется; фикстура остаётся в git.
- Следующая работа — архитектура вспомогательных файлов проекта: спеки, тикеты, ADR, глоссарий,
  исследования, память. Для каждого — где он живёт и что с ним происходит, когда работа завершена,
  отменена или изменена.

## Consequences

- ADR 0004 действует, кроме условия пересмотра и «следующего приоритетного замера».
- README стенда `pipeline-ab` помечает L2 как непрогнанный и ссылается сюда.
